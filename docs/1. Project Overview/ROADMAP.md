# Project Roadmap

The strategic development path for C# Academy, moving from a core learning platform to an advanced educational ecosystem.

---

## ✅ v1.0.0 - Foundation (Completed)
- Clean Architecture implementation.
- Basic course/lesson structure.
- Identity & JWT Authentication.
- Roslyn Code Execution sandbox.
- Initial Gemini AI assistant.

---

## 🚀 v1.1.0 - Interactive & Polished (Current)
- **Gamification 2.0**: Unified XP/Streak system with `MaxStreak` tracking.
- **Dynamic Audio**: full `SoundContext` integration for all key interactions.
- **Notifications**: Visual achievement popups and info toasts.
- **Content Expansion**: 5+ full courses with quizzes and videos.
- **Admin/Teacher Portals**: Complete classroom management and content authoring suites.
- **Voice Narrative**: Integrated speech synthesis for lesson summaries.
- **Certifications**: Automated PDF issuance with verification.

---

## 🏗️ v1.2.0 - Community & Depth (Q3 2026)
- **Live Coding Pairing**: Collaborative editor for teacher-student debugging.
- **Forum/Q&A**: A lesson-specific discussion board for peer learning.
- **Offline Support**: PWA (Progressive Web App) support for offline reading.
- **Advanced Gamification**: Weekly leagues and unlockable profile avatars.

---

## 🔮 v2.0.0 - AI Mentorship (Future)
- **Personalized Learning Paths**: AI adjusts course difficulty based on student performance.
- **Voice-to-Code**: Command-based coding exercises for improved accessibility.
- **Enterprise Integration**: White-labeling support for universities and bootcamps.
- **Mobile Apps**: Native iOS and Android versions using React Native.

---

## ⚠️ Known Limitations (v1.1.0)
- **Roslyn Sandbox**: Standard output is captured but standard input (`Console.ReadLine`) is not fully supported in the Playground.
- **Browser Compatibility**: Voice narration depends on the availability of the browser's Web Speech API.
- **Video Providers**: Currently optimized only for YouTube; manual embed URLs required for other providers.
